## 📌 Descripción

**Uber Clone** es una aplicación móvil desarrollada en **Android nativo (Java)** que replica las funcionalidades principales de una plataforma de transporte bajo demanda.

El sistema permite la conexión entre usuarios y conductores, integrando servicios en tiempo real mediante Firebase para ofrecer una experiencia dinámica, rápida y escalable.

---

## 🚀 Características

- 📱 Aplicación Android nativa
- 🚖 Solicitud de viajes en tiempo real
- 📍 Geolocalización de usuarios
- 🔐 Autenticación con Firebase
- 🔄 Base de datos en tiempo real
- ☁️ Almacenamiento en la nube
- ⚡ Interfaz fluida y responsiva

## 🔧 Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/tuusuario/UberClone.git
```
Abrir en Android Studio
Configurar Firebase:
```
Crear proyecto en Firebase
Descargar google-services.json
```
Agregarlo en /app

Ejecutar la aplicación en un emulador o dispositivo físico
